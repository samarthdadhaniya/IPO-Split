# Odoo X MSU 🚀

## Introduction 💡

Welcome to **Odoo X MSU**, a platform designed to bridge the gap between capital-constrained retail investors and funding partners to increase IPO allotment chances. This website allows users to collaborate, apply for IPOs from multiple PAN accounts, and track real-time updates, offering a seamless investment experience for retail investors.

---

## Unique Features 🌟

- **IPO Partnership**: Connects fund-seeking users with investors to increase IPO allotment chances.  
- **Multiple PAN Applications**: Users can apply for IPOs using multiple PAN accounts, improving their chances of allotment.  
- **Dynamic Matching Algorithm**: A smart algorithm that automatically pairs investors with users based on preferences, funds, and availability.  
- **Real-Time IPO Updates**: Provides up-to-date information on IPO listings, deadlines, and statuses.  
- **Choice-Based Matching System**: Efficiently matches investors with suitable users and PAN holders for optimized IPO applications.

---

## Tech Stack 🛠️

- **Frontend**:
  - React.js ⚛️
  - Tailwind CSS 🎨
  - Firebase Auth / OAuth (Google, PAN verification API) 🔐
  
- **Backend**:
  - Node.js with Express.js 🌐
  - PostgreSQL (Primary) + Redis (Caching) 🗄️

- **Deployment & Infrastructure**:
  - Cloud Provider: AWS ☁️

---

## Features of the Website 🌐

- **User Authentication**: Secure login system using OTP-based authentication for seamless access.  
- **IPO Listings**: Browse and select IPOs with detailed information, such as price, lot size, and deadlines.  
- **Investment Partnership**: Find and connect with investors to fund IPO applications with predefined profit-sharing agreements.  
- **PAN Holder Matching**: Allows users to apply for IPOs using multiple PAN accounts, increasing the chances of success.  
- **Real-Time Notifications**: Get alerts for IPO openings, partnership status, and fund transfer updates.  
- **Transaction Tracking**: Track your investment, profit distribution, and IPO allotment status in real-time.  
- **Performance Dashboard**: View past partnerships, successful IPO applications, and your trust score.

## How to Install Locally 🖥️

Follow these steps to set up the website on your local machine:

### 1. Clone the Repository 📥
Clone this repository using the following command:
```bash
git clone https://github.com/samarthdadhaniya/IPO-Split
```

### 2. Install Dependencies 📦
Navigate to the project folder:
```bash
cd odoo-x-msu
```

Install the necessary dependencies using `npm` or `yarn`:
```bash
npm install
# or
yarn install
```

### 3. Set Up Environment Variables 🔑
Create a `.env` file in the root of the project and add your environment variables (e.g., Firebase credentials, database configurations). Make sure you have the correct API keys for PAN verification and OAuth authentication.

### 4. Start the Development Server 🚀
Run the development server using:
```bash
npm start
# or
yarn start
```

Now, open your browser and visit `http://localhost:3000` to view the website.
